# CommuteNEXT website

This repository contains only the public, static CommuteNEXT website and privacy policy. It does not contain the iOS app source code.

GitHub Pages publishes the `main` branch from the repository root at `https://syphon1205.github.io/CommuteNEXT/`.

The privacy policy is at `https://syphon1205.github.io/CommuteNEXT/privacy/`. Update `privacy/index.html` when the app's data practices change, and keep the policy links in the app current.
